# Northstar Dashboard

A responsive business analytics dashboard built with React, TypeScript, Vite, and Recharts.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The dashboard includes responsive KPI summaries, a revenue trend with selectable date ranges, recent customer activity, and a CSV report export.

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run typecheck` checks the TypeScript project references.
- `npm run build` type-checks and creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
